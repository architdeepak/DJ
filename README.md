# Airdeck

Airdeck is a browser DJ mixer with two decks, audio effects, and optional webcam hand controls. It is built with JavaScript, Vite, Web Audio, and MediaPipe.

Install Node.js 22.12 or newer and run:

```bash
npm install
npm run dev
```

Open the local address printed by Vite. You can load the demo tracks or your own audio files. Camera controls are optional; the mixer also works with the keyboard and on screen controls.

To build the app for hosting, run `npm run build`. The output is in `dist/`.
